# Presentation assets

- [`banner.svg`](banner.svg) is the editable vector artwork used in the project README. It contains its own accessible title and description and loads no external resources.
- [`social-preview.png`](social-preview.png) is the same artwork rendered at 1280 × 640 pixels, ready for GitHub's repository social preview.

To activate the social card, upload `social-preview.png` in the repository's **Settings → General → Social preview**. The image meets GitHub's [recommended dimensions and file-size limit](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

When editing the artwork, retain the SVG's `title` and `desc` elements and regenerate the PNG. The artwork uses DejaVu Sans and DejaVu Sans Mono, with generic fallback fonts, and is covered by the project's [MIT license](../../LICENSE).
